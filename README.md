# 🚀 Portfólio Profissional

Bem-vindo ao repositório do meu portfólio profissional! Este projeto foi desenvolvido para apresentar minha trajetória, habilidades técnicas, projetos em destaque e formas de contato na área de desenvolvimento de software.

🔗 **Acesse o site ao vivo:** [mateus8hen.github.io/Portifolio](https://mateus8hen.github.io/Portifolio/)

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias modernas de desenvolvimento web para garantir uma experiência fluida, responsiva e visualmente atraente:

* **HTML5** & **CSS3** (com design responsivo e estilização moderna)
* **JavaScript** (para interatividade e dinamismo)
* **Git & GitHub Pages** (para controle de versão e hospedagem contínua)

## ✨ Funcionalidades

* **Apresentação Pessoal:** Seção dedicada a introduzir minha formação, objetivos e paixão por tecnologia.
* **Projetos em Destaque:** Vitrine interativa com os principais sistemas, aplicações e scripts desenvolvidos.
* **Habilidades Técnicas:** Listagem de linguagens de programação, frameworks e ferramentas que utilizo no dia a dia.
* **Contatos & Redes Sociais:** Links diretos para conexões profissionais, e-mail e repositórios.
